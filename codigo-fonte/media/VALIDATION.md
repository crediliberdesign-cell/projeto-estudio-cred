## Repairs discovered in real tests

- PyAV 19 removed `av.open(metadata_errors=...)` used by faster-whisper 1.2.1. Direct pin av==16.0.1 and regenerated hashed Windows lock fixed actual ASR execution.
- Brand font copy changed from shutil.copy2 to copyfile: propagating protected macOS font attributes caused an error, whereas copying bytes is sufficient and preserves the source.
- An initial Chromium root-loading timeout occurred under host resource pressure. Subsequent exports succeeded; browser render timeout increased to 60 seconds. Timeouts remain reported failures, not success.
- Font rendering now awaits actual font loading before measuring typography. Missing assets/unsupported glyphs have explicit notices.

## Reproducibility and boundaries

- requirements.lock generated by uv 0.8.22 for Python 3.12, x86_64-pc-windows-msvc, all transitive package hashes. Install with --require-hashes and --only-binary :all:; this is dependency resolution, not proof every Windows wheel was executed here.
- All Remotion packages aligned to 4.0.539 with npm package-lock integrity entries. Chromium is prefetched by installer before offline use.
- Runtime CUDA libraries are private NVIDIA wheels; worker adds cublas/cudnn/cuda_runtime/cuda_nvrtc bin directories before CTranslate2. Only reported float16/float32 is selected on CUDA. GPU runtime failure retries CPU and emits an explicit warning.
- HF offline and telemetry opt-out flags set during transcription; ONNX telemetry explicitly disabled through its API. The tested ONNX build still logs an import-time device-ID initialization warning on macOS; no content upload was requested. Local operation does not require HF login.
- No arbitrary generated code/shell is executed by media tools. Motion is bounded typed scenes; user text is React-escaped; active/external SVG content rejected. This is not a general native-shell sandbox.
- Speech recognition errors, amplitude-based silence ambiguity, and visual/layout edge cases require operator review. No automatic virality claims or frame-perfect speech alignment guarantee.
