# Worker contract

`python media/worker.py --request job.json`

UTF-8 JSON-lines stdout events: `{type:"progress",stage,progress?}` (0–1 only when measurable), final `{type:"result",...}`; errors `{type:"error",message,recoverable}` and exit 1. Parent should persist all events, create a fresh output_dir each job, own Windows process tree, and enforce cancellation/timeout. Worker polls `cancel_file` and terminates its owned FFmpeg/Node process; long model calls may wait until the next recognized segment, so parent process-tree termination is required for immediate cancellation.

All requests: `action`, `output_dir`, executable paths `ffmpeg`, `ffprobe`, `node`; `allowed_roots` includes explicitly approved original assets and generated files used as input; `input` source file for media actions; `whisper_model_path` predownloaded local CTranslate2 model folder; `remotion_dir` managed template folder. Python does not download models. No shell execution.

Project: `{duration:number|"source", aspect:"9:16"|"16:9"|"1:1"|"4:5"|"source",resolution:number, brand_snapshot:{name,colors:[{hex,role}],fonts:[{path,family,role,weight}],logos:[{path}]}, audio:{mode:"original"|"none"|"music"|"narration"|"mix",music_path?,narration_path?,original_level?,music_level?,narration_level?}}`. `resolution` is the SHORT dimension. Fields belong to individual project. Brand snapshot never supplies duration/aspect/audio. Audio original is a reversible editing fallback; motion without source reports no original audio.

- `probe`: result metadata duration, fps, dimensions (display rotation honored), audio tracks, HDR/VFR indication.
- `frames`: options count 1–20. Result `frames:[{time,path}]`, sampling limitation.
- `transcribe`: options language defaults pt. Result `transcript_path`, `segments:[{start,end,text,words:[{start,end,word,probability}]}]`, actual device/compute/warnings. Turbo multilingual model fixed by installer. Failed CUDA retries CPU and explicitly reports this.
- `plan_silence`: options threshold_db(-38), minimum_silence(.65), handles(.16). Result `timeline:{version,fps,duration,segments:[{source_start,source_end,output_start,output_end}]}`, removed_seconds, warning, plan_path. No mutation/export.
- `captions`: options transcript_path OR transcript object or automatically transcribes; caption_size, highlight_words; result srt,vtt,ass,captions_json,count,warnings. Transcript times are original source times. `edit` remaps to cut timeline automatically.
- `edit`: options ranges [{start,end}] OR remove_silence:true, captions, burn_captions (defaults true when captions enabled), transcript_path OR transcript object, improve_audio, fit:"contain"|"cover", preview:boolean,use_nvenc:boolean. Result output (MP4), preview_image, timeline JSON path, captions object, output probe, original_unchanged,warnings. All exports reencode video/audio together. Contain preserves content by default. Silence-only detection is amplitude-based; preview/review recommended. improve_audio is moderate FFmpeg noise reduction/loudness, not repair guarantee. Music/narration is only supplied local media; no TTS. GPU encoding falls back to CPU.
- `motion` / `carousel`: requires individual project.aspect (motion also numeric duration). options scenes [{type:"title"|"lower-third"|"logo"|"kinetic"|"callout"|"card"|"explainer",title,body,eyebrow?,duration?}], or title/body fallback, preview_only. Result output MP4 or images[] PNG, preview_image,motion_project,warnings. Uses template-generated React only, never executes user-generated code. Exact scene source is persisted motion.json. Carousel duration is internal animation capture, not company/project default.
- `diagnose`: actual FFmpeg filters, versions, 0.25sec NVENC encode, CPU/GPU compute availability (not falsely a transcription test).
- `extract_document`: input PDF/DOCX, result chunks:[{text,page,section?}], warnings,status,sha256. Scanned PDF text absent explicitly warns OCR unavailable. Other text formats root handles.

Embedded Player: after `npm ci`, run `npm run build:player`. Serve dist/player.html and player.bundle.js same origin. Send iframe `postMessage({type:'motion-preview',props:motionJSONWithAssetBase},location.origin)` after `motion-player-ready`; `assetBase` must be same-origin authorized job asset serving URL. Player rejects cross-origin events. Runtime preview also available as generated PNG/MP4 to avoid requiring Studio.

No Windows or RTX hardware validation is implied by source files. Preserve job request (without secrets), timeline, probe, output and report actual validation. Filesystem scope must still be checked at parent API boundary; caller-supplied executable paths/allowed_roots are trusted app config, not model inputs.
- `inspect_font`: input local TTF/OTF/WOFF2, result family/style/weight/portuguese_supported/missing_glyphs from actual font tables. Motion independently inspects imported fonts; root may use this action during onboarding. Unsupported active/external SVG references are rejected in motion assets.

Motion can also take an `input` video: actual footage is copied into the job asset folder and composed behind the graphics. `project.aspect=source` and `project.duration=source` are allowed when a source exists; original audio obeys project.audio. Caller supplies ffprobe. HDR footage is explicitly rejected for motion until first converted to SDR through edit. The `fit` option defaults contain. Supplied music/narration is mixed by Remotion; no audio is invented. No silent repetition when requested duration exceeds the source.
